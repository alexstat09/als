# Το json ενός κεφαλαίου — κάθε πεδίο, με παράδειγμα από το Δ2

Σήμανση σε ΚΑΘΕ κείμενο: `*όρος*` (Didot πλάγια, χρώμα) · `**έμφαση**`. Τίποτα άλλο, κανένα HTML.
`a` = πίνακας **άγκυρων**: φράσεις ΑΥΤΟΛΕΞΕΙ από την πηγή. Το κείμενο δίπλα τους πρέπει να λέει τις λέξεις τους.
Τα πεδία με ⚙ τα γράφει το `scaffold.js` — δεν τα αγγίζεις.

## Κορυφή
```json
"_": "Δ2 · … ⛔ Μόνο εδώ γράφεται το κεφάλαιο…",            ⚙ σχόλιο
"file": "arxaia-sokratis-ideas.html",                      ⚙ (--file) — filename == URL
"key": "eisarx-d2-v1",                                     ⚙ το ΜΟΝΟ κλειδί της σελίδας (νέα: eisarx-<id>-v1)
"route": "Δ2",                                             ⚙ από την επικεφαλίδα του βιβλίου
"back": { "href": "arxaia.html#gn", "label": "Αρχαία" },  ⚙
"source": { "file": "tests/…source.txt", "sha": "…" },    ⚙ ⛔ ποτέ με το χέρι
"title": "Οι φιλοσοφικές ιδέες του Σωκράτη",               ⚙ ο τίτλος του βιβλίου
"counted": { "8": "οι σταθμοί της σελίδας" },             αριθμοί που ΜΕΤΡΗΣΕΣ εσύ (δεν είναι στο βιβλίο)
"names": ["…"],                                            (σπάνια) κύριο όνομα εκτός βιβλίου που χρειάζεται
"plate": { "d": "Α, β, γ" },                               (προαιρετικό) περιγραφή της πλάκας στον Γνωστό —
                                                           ΕΝΑ κόμμα ανά μέρος· χωρίς αυτό = οι ετικέτες των σταθμών
```

## cover · core · fin
```json
"cover": {
  "kicker": "Κεφάλαιο Δ2 · 8 σταθμοί",                    ⚙ (διόρθωσε το πλήθος αν ξανάσπασες σταθμούς)
  "sub": { "t": "Διαλεκτική, μαιευτική, ειρωνεία. Η αναζήτηση των ορισμών, …",
           "a": ["Διαλεκτική, μαιευτική, ειρωνεία.", "Η αναζήτηση των ορισμών, η επαγωγική μέθοδος", "και η ηθική"] },
  "motto": { "gr": "Ἓν οἶδα, ὅτι οὐδὲν οἶδα.", "tr": "Ένα ξέρω: ότι δεν ξέρω τίποτα.", "a": ["Ἓν οἶδα, ὅτι οὐδὲν οἶδα."] },
  "seal": { "img": "eisagogi-sokratis.webp", "credit": "W. Meyer, ξυλογραφία … · κοινό κτήμα · Wikimedia Commons",
            "mark": "Σ", "ring": "ΣΩΚΡΑΤΗΣ · ΕΝ ΟΙΔΑ ΟΤΙ ΟΥΔΕΝ ΟΙΔΑ ·", "label": "Η προτομή του Σωκράτη, σε χαρακτικό, …" }
},
"mapTitle": "Από τον χρησμό ως το συμπέρασμα",          ⭐ ΥΠΟΧΡΕΩΤΙΚΟ σε κάθε νέο κεφάλαιο (ο τίτλος του χάρτη· als-v677)
"core": "οὐδὲν οἶδα",                                      η φράση στη μέση του αστερισμού (σύντομη)
"fin": { "line": "Ο Σωκράτης έκλεισε.", "next": "Πέρνα στον Έλεγχο: …" }
```
- `motto.gr` αυτολεξεί (μπαίνει σε Didot). Χωρίς μότο στο βιβλίο → μια φράση-κλειδί του κεφαλαίου, αυτολεξεί.
- `seal.img`/`credit` τα γράφει το `bust.js --pick`. `mark`/`ring`/`label` ΠΑΝΤΑ (fallback χωρίς εικόνα · αναγνώστης οθόνης).

## stations[] — ένας σταθμός
```json
{
  "n": 4, "short": "Η αμφισβήτηση", "xy": [535, 105],     ⚙ n 1…N · short 2–3 λέξεις (χάρτης) · xy ⚙ (κύμα, 1100×380)
  "label": "Η σωκρατική αμφισβήτηση", "la": ["Η σωκρατική αμφισβήτηση."],
                                                           ετικέτα· `la` = άγκυρα ΑΝ η ετικέτα είναι πλαγιότιτλος του βιβλίου
  "title": "Όχι άρνηση, αναζήτηση",                       ο τίτλος του σταθμού — ελεύθερος, δικός σου
  "mine": "Η αντιμετώπιση του Σωκράτη…",                  (μόνο Δ2-τύπου) χειρόγραφος πλαγιότιτλός ΤΟΥ, από φωτογραφία
  "prose": [ { "t": "Ο Σωκράτης δεν ήταν άθεος, ήταν όμως **είρωνας** …", "a": ["Ο Σωκράτης δεν ήταν άθεος, ήταν όμως είρωνας"] } ],
  "quote": { "from": "ἐπὶ Σωκράτους δὲ", "to": "ἀπέκλιναν οἱ φιλοσοφοῦντες", "close": true,
             "lead": "Η πολύ καλύτερη διατύπωση του Αριστοτέλη", "cite": "Αριστοτέλης, Περὶ ζῴων μορίων 642 a 28 κ.εξ.",
             "a": ["Για να χρησιμοποιήσουμε δηλαδή την πολύ καλύτερη διατύπωση του Αριστοτέλη", "Περὶ ζῴων μορίων , 642 a 28 κ.εξ."] },
  "diagram": { "type": "fork", … },                       ΕΝΑ σχέδιο — βλ. diagrams.md
  "points": [ { "t": "Ο τρόπος: πλησίαζε όσους θεωρούνται σοφοί …", "a": ["πλησίασα κάποιον από αυτούς που θεωρούνται σοφοί"] } ],
  "mnem": { "k": "ΑΡΝΗΣΗ / ΑΝΑΖΗΤΗΣΗ", "t": "Και οι δύο αμφισβητούν. …", "a": ["κατέληγε στην άρνηση"] },
  "gloss": [
    { "k": "ἁπάντων σοφώτατος", "d": "ο σοφότατος απ’ όλους", "a": ["ἁπάντων σοφώτατος"] },
    { "k": "αντιφατικά αισθήματα", "d": "αντικρουόμενα", "mine": true }
  ]
}
```
- `prose` = 1–3 παράγραφοι που ανοίγουν τον σταθμό· `points` = τα σημεία (κουκκίδες), 2–5, «Ο τρόπος: …» / «Το τίμημα: …».
- `quote`: `from`/`to` = η αρχή και το τέλος, αυτολεξεί· το κείμενο κόβεται από την πηγή. `close:true` όταν το βιβλίο ξεχνά
  να κλείσει εισαγωγικά (δήλωσέ το και στο `colophon`). `lead` = εισαγωγική φράση πάνω από το απόσπασμα.
- `mnem` (προαιρετικό): `k` = ΚΕΦΑΛΑΙΑ, `t` = η εξήγηση. Δεν ελέγχεται για «λέει την άγκυρα» (είναι δικό σου)· οι `a`
  του δεν είναι υποχρεωτικές, αλλά βάλ' τες — αν υπάρχουν, πρέπει να είναι αυτολεξεί.
- `gloss` = Λεξιλόγιο δεξιά: `k` όρος του βιβλίου (αυτολεξεί), `d` απόδοση. `mine:true` = σημείωση ΤΟΥ (χωρίς `a`).

## traps[] (για τον validator — δεν ζωγραφίζονται)
```json
{ "claim": "ο Σωκράτης ήταν άθεος", "why": "ΔΕΝ ήταν άθεος, ήταν είρωνας· το «άθεος» είναι ισχυρισμός των κατηγόρων" }
```
`claim` = η λάθος διατύπωση (μικρά, σύντομη)· απαγορεύεται σε ό,τι διαβάζεται ως αληθές. Πάνω τους χτίζεις τα Σ/Λ `ok:false`.

## check — ο Έλεγχος
```json
"recall":   { "id": "r03", "s": 1, "q": "Ποιος πήγε στους Δελφούς, τι ζήτησε και τι απάντησε ο θεός;",
              "r": "Ο Χαιρεφών, φίλος του Σωκράτη. Ζήτησε …", "a": ["Ο Χαιρεφών, φίλος του Σωκράτη", "…"] }
"tf":       { "id": "t02", "s": 1, "ok": false, "t": "Ο χρησμός ολόκληρος … παρατίθεται μέσα στο απόσπασμα της Ἀπολογίας.",
              "why": "Λάθος. Τον δίνει η υποσημείωση του βιβλίου, …", "a": ["Σύμφωνα με μία μεταγενέστερη πληροφορία, ο χρησμός έλεγε"] }
"mc":       { "id": "m03", "s": 1, "q": "Ποιος πήγε στο μαντείο των Δελφών;", "o": ["Ο Κριτίας", "Ο Αλκιβιάδης", "Ο Χαιρεφών", "Ο Μέλητος"],
              "ok": 2, "why": "Ο Χαιρεφών, φίλος του Σωκράτη· …", "a": ["Ο Χαιρεφών, φίλος του Σωκράτη"] }
"numbers":  { "v": "20-21", "l": "Ἀπολογία: από εκεί είναι το απόσπασμα", "s": 2, "a": ["Ἀπολογία , 20-21"] }
"numbersNote": "Και οι δύο αριστοτελικές παραπομπές κλείνουν με «κ.εξ.», δηλαδή «και εξής».",
"pitfalls": { "s": 4, "t": "«Ήταν άθεος»: όχι, ήταν είρωνας. …", "claim": true, "a": ["Ο Σωκράτης δεν ήταν άθεος, ήταν όμως είρωνας"] }
"idea":     { "t": "Ο Σωκράτης παίρνει την αμφισβήτηση … και της αλλάζει κατεύθυνση: …", "a": ["…"] }
```
- ids: `r01…`, `t01…`, `m01…`, μοναδικά. `s` = ο σταθμός όπου ζει η απάντηση (το «Τα κενά μου» στέλνει εκεί).
- `recall`: η ερώτηση ΚΑΙ η απάντηση μαζί πρέπει να λένε τις άγκυρες. `tf.why` αρχίζει «Σωστό.»/«Λάθος.».
- `mc.ok` = δείκτης 0–3 της σωστής· μοίρασέ τον σε όλες τις θέσεις. ⛔ Καμία λάθος επιλογή γραμμένη μέσα στην ερώτηση.
- `pitfalls.claim:true` όταν το `t` γράφει την παγίδα σε εισαγωγικά (για να μη χτυπήσει ο φρουρός των traps).

## colophon[] (δεδομένα· ΔΕΝ ζωγραφίζεται)
Από πού είναι το κείμενο + κάθε δηλωμένη απόκλιση από το βιβλίο (εισαγωγικά που κλείσαμε, σημειώσεις του από φωτογραφία).
