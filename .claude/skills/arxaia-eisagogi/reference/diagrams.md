# Τα 8 σχέδια του καλουπιού — πότε ταιριάζει το καθένα

Κάθε `{ "t": …, "a": [...] }` μέσα σε σχέδιο είναι κείμενο που φαίνεται, άρα **ελέγχεται** (άγκυρα αυτολεξεί + το κείμενο
λέει την άγκυρα, «short» = αρκεί 1 λέξη). Κράτα τα ΣΥΝΤΟΜΑ: ετικέτα 2–6 λέξεις, `sub` ως ~10 — το `.dg` κόβει ό,τι ξεχειλίζει
και το test το μετράει στα 390px. `*όρος*` επιτρέπεται. Δύο διαδοχικοί σταθμοί ΔΕΝ έχουν τον ίδιο τύπο.
Δες έναν ζωντανό: `node -e "console.log(JSON.stringify(require('./tools/eisagogi/arxaia/sokratis-d2.json').stations[N-1].diagram,null,1))"`.

| Τύπος | Ταιριάζει όταν το βιβλίο λέει… | Δ2 |
|---|---|---|
| `flow` | μια **αλυσίδα** γεγονότων/προσώπων: Α → Β → Γ | I · ο χρησμός |
| `repeat` | μια **δοκιμή που επαναλαμβάνεται** με ίδιο αποτέλεσμα (κύκλος) | II · ο έλεγχος του χρησμού |
| `split` | **δύο αντίθετες αντιδράσεις** στο ίδιο πράγμα, με κοινή κατάληξη | III · θεϊκό / μίσος → καταδίκη |
| `fork` | **σύγκριση δύο πλευρών** σε σειρά κριτηρίων (κοινή ρίζα) | IV · σοφιστές / Σωκράτης |
| `dialogue` | μια **μέθοδος σε βήματα** με ρόλους (ποιος κάνει τι), σε φάσεις | V · διαλεκτική + μαιευτική |
| `descent` | μια **μετατόπιση** από ένα επίπεδο σε άλλο (πάνω → κάτω), με αρχαίο παράθεμα | VI · από τα άστρα στη γη |
| `ladder` | μια **άνοδος σε σκαλιά** από το χαμηλό στο ψηλό (παράδειγμα → γενίκευση) | VII · επαγωγική μέθοδος |
| `scales` | **ζεύγη αντιθέτων** (απαρίθμηση) + ένα νήμα που τα δένει | VIII · τα 6 ζεύγη |

Για βίο/χρονολόγιο (Πλάτων, Αριστοτέλης): `flow` (σταθμοί ζωής) · `ladder` (άνοδος/εξέλιξη) · `split` (δύο εκδοχές) ·
`fork` (σύγκριση δύο έργων/φιλοσόφων). Για περιεχόμενο έργου (Ηθικά, Πολιτικά): `scales` (αντίθετα) · `ladder` (ιεραρχία) ·
`dialogue` (επιχείρημα σε βήματα) · `descent` (από το γενικό στο ειδικό).

## Τα σχήματα (μικρά παραδείγματα, από το Δ2)
```json
{ "type": "flow", "nodes": [ { "t": "Ο Χαιρεφών", "a": ["Ο Χαιρεφών"], "sub": { "t": "φίλος του Σωκράτη", "a": ["φίλος του Σωκράτη"] } }, … ] }

{ "type": "repeat",
  "top":    { "t": "«σοφός δεν είμαι» — «ο θεός δεν είναι δυνατόν να ψεύδεται»", "a": [...] },
  "stops":  [ { "t": "ένας από τους πολιτικούς", "a": [...], "find": { "t": "φαινόταν σοφός, αλλά σοφός δεν ήταν", "a": [...] } }, … ],
  "result": { "t": "αυτός νομίζει πως ξέρει · εγώ δεν νομίζω πως ξέρω", "a": [...] },
  "cost":   { "t": "και το μίσος «και αυτού και άλλων πολλών»", "a": [...] } }

{ "type": "split", "lh": { "t": "κάτι το θεϊκό", "a": [...] }, "rh": { "t": "το μίσος", "a": [...] },
  "left": [ { "t": "ο Αλκιβιάδης", "a": [...] }, … ], "right": [ { "t": "οι θιγόμενοι και οι οπαδοί τους", "a": [...] }, … ],
  "result": { "t": "η θανατική καταδίκη του", "a": [...] } }

{ "type": "fork", "root": { "t": "αρνούνται να δεχτούν ως δεδομένο …", "a": [...] },
  "lh": { "t": "Οι σοφιστές", "a": [...] }, "rh": { "t": "Ο Σωκράτης", "a": [...] },
  "rows": [ { "l": { "t": "καταλήγουν στην **άρνηση**", "a": [...] }, "r": { "t": "**θετική αμφισβήτηση**", "a": [...] } }, … ] }

{ "type": "dialogue",
  "phases": [ { "t": "αναίρεση", "a": [...], "from": 0, "to": 2 }, { "t": "νέο συμπέρασμα", "a": [...], "from": 3, "to": 4 } ],
  "steps":  [ { "w": "ο συνομιλητής", "t": "εκθέτει μια άποψη που θεωρεί ολοκληρωμένη και θεμελιωμένη", "a": [...] }, … ],
  "result": { "t": "η γενική αλήθεια, ανεξάρτητη …", "a": [...] } }
   ↳ phases.from/to = δείκτες στα steps (0-based), συνεχόμενοι, χωρίς κενά.

{ "type": "descent", "top": { "t": "τα φυσικά φαινόμενα", "a": [...] }, "topNote": { "t": "έγιναν αντικείμενο της επιστήμης …", "a": [...] },
  "topGr": { "t": "*τὸ ζητεῖν τὰ περὶ φύσεως ἔληξε*", "a": [...] },
  "bottom": { "t": "ο ίδιος ο άνθρωπος και η κοινωνία", "a": [...] }, "bottomGr": { "t": "*περὶ δὲ τὴν χρήσιμον ἀρετὴν …*", "a": [...] } }

{ "type": "ladder", "lo": { "t": "η εμπειρία", "a": [...] }, "hi": { "t": "πέρα από την εμπειρία", "a": [...] },
  "rise": { "t": "*ἐπακτικοὶ λόγοι*", "a": [...] },
  "steps": [ { "t": "παραδείγματα", "a": [...], "sub": { "t": "από την καθημερινή ζωή και εμπειρία", "a": [...] } }, … ] }

{ "type": "scales", "pairs": [ { "l": "το καλό", "r": "το κακό", "a": ["του καλού και του κακού"] }, … ],
  "thread": { "t": "η λογική σκέψη, όχι οι αισθήσεις", "a": [...] } }
   ↳ pairs: l/r είναι σκέτα κείμενα, ΜΙΑ άγκυρα για το ζεύγος.
```

## Νέος τύπος (μόνο αν ΚΑΝΕΝΑΣ δεν ταιριάζει)
`DG.<τύπος>` + CSS `.dg-<τύπος>` στο `page.tpl` + έλεγχος στο `tests/arxaia-eisagogi.test.js`, **στο ίδιο commit**·
μετά `finish.js sokratis-d2` πρέπει να μείνει πράσινο (ο Δ2 byte-ίδιος). Ο validator διαβάζει τους τύπους από το `DG`.
