# Τα 8 σχέδια του καλουπιού — πότε ταιριάζει το καθένα

Κάθε `{ "t": …, "a": [...] }` μέσα σε σχέδιο είναι κείμενο που φαίνεται, άρα **ελέγχεται** (άγκυρα αυτολεξεί + το κείμενο
λέει την άγκυρα, «short» = αρκεί 1 λέξη). Κράτα τα ΣΥΝΤΟΜΑ: ετικέτα 2–6 λέξεις, `sub` ως ~10 — το `.dg` κόβει ό,τι ξεχειλίζει
και το test το μετράει στα 390px. `*όρος*` επιτρέπεται.

## ⭐⭐ Οι κανόνες του ΝΟΗΜΑΤΟΣ (als-v746/747/749 — αντικαθιστούν το παλιό «όχι ίδιος τύπος διαδοχικά»)
Ο παλιός κανόνας έκανε τον τύπο να διαλέγεται με ΣΕΙΡΑ, όχι με ΝΟΗΜΑ → ο Αλεξ: «τα σκετσάκια δεν βγάζουν νόημα…
"η δικαιοσύνη" και δίπλα "επικρατεί το χάος"». Πριν από κάθε σχέδιο γράψε σε ΜΙΑ πρόταση τι ΙΣΧΥΡΙΖΕΤΑΙ το σχήμα του
(βέλος = «άρα/μετά», ζυγαριά = «αντίθετα», σκάλα = «ανεβαίνει από… σε…», δύο στήλες = «σύγκριση Χ με Υ») — πρέπει να
είναι ΑΛΗΘΙΝΗ κατά το βιβλίο.
1. **Ο ΤΥΠΟΣ ΑΠΟ ΤΟ ΝΟΗΜΑ.** `flow` = μόνο πραγματική χρονική σειρά ή αιτία→αποτέλεσμα (όχι πρόβλημα→λύση: Πολιτεία Β 1
   «δημαγωγοί → κλήρωση → βοή → φιλόσοφοι» διαβαζόταν ως αιτία → έγινε `split` «Το πρόβλημα | Η μοναδική ελπίδα»)·
   `ladder` = μόνο όταν το βιβλίο λέει άνοδο/ιεραρχία (Πολιτεία Α θέμα: `ladder` → flow, γιατί το βιβλίο απλώς απαριθμεί)·
   `scales` = μόνο ΑΛΗΘΙΝΑ αντίθετα, ίδιας κατηγορίας σε κάθε γραμμή — ΔΕΝ έχει επικεφαλίδες, άρα όχι όπου χρειάζονται
   (σπήλαιο Β10: ανόμοια ζεύγη → `fork` «Άλλα λέγει | Άλλα εννοεί»· δημιουργοί Α: → `fork` «Μπορεί | Δεν μπορεί»)·
   `fork` = σύγκριση δύο πλευρών με `lh`/`rh` (Β7 οι 5 ορισμοί: «Ποιος στον διάλογο | Δικαιοσύνη είναι…»)·
   `split` = δύο πλευρές με κοινή κατάληξη · `dialogue` = ενστάσεις → απάντηση, με `lanes` που λένε ΠΟΙΟΣ μιλάει.
2. **`sameAsPrev`.** Ίδιος τύπος σε διαδοχικούς σταθμούς ΕΠΙΤΡΕΠΕΤΑΙ μόνο δηλωμένος στον σταθμό:
   `"sameAsPrev": "<γιατί η ιδέα έχει το ίδιο σχήμα, ≥10 χαρ.>"` (Πολιτεία Β 2: δύο `split` πρόβλημα → λύση).
   Το test το ελέγχει. **Νόημα > ποικιλία.**
3. **`flow` ≤ 3 κόμβοι.** Ο 4ος τυλίγεται σε στενή στήλη και διαβάζεται λέξη-λέξη στα 1440 (μετρημένο σε φωτογραφία).
   Περισσότερα βήματα → `ladder` (αν ανεβαίνει: δρόμος των φυλάκων 20–30 · 30–35 · 50) ή σπάσε τον σταθμό.
4. **Επικεφαλίδα σε ΚΑΘΕ πλευρά/στήλη/λωρίδα:** `lh`/`rh`, `lanes`, `topCap`/`bottomCap`, `resCap`, `lo`/`hi`.
5. **Κάθε κουτάκι = μια ΟΛΟΚΛΗΡΗ μικρή ιδέα** που καταλαβαίνεται χωρίς την πρόζα — όχι κομμένη φράση
   («Οι Τριάκοντα» με ονόματα, όχι «οι συγγενείς του»).
6. **Σταθμός με ΔΥΟ ιδέες → σπάσ' τον στα δύο** (Πολιτεία Α 3 → 3 «Η πεποίθηση» flow + 4 «Η δικαιοσύνη» fork· τότε
   ξαναμοίρασε τα `s` του Ελέγχου, τα `xy`, και διόρθωσε το `counted`).
7. **⛔ ΙΕΡΑΡΧΙΑ = ΑΝΩΤΕΡΟ ΠΑΝΩ.** Όταν οι γραμμές ενός σχεδίου (fork/scales/λίστα) είναι ιεραρχία ή κλίμακα, η
   κατακόρυφη θέση ΣΗΜΑΙΝΕΙ — το ανώτερο ΠΑΝΩ, ΠΟΤΕ με τη σειρά της φράσης του βιβλίου (Πολιτεία Α 8, als-v749:
   χειρώνακτες/δημιουργοί πρώτη γραμμή → «οι δημιουργοί πάνω» → αντεστράφη). Η σκάλα ήδη: κάτω-αριστερά → πάνω-δεξιά.
8. **Η ΔΕΞΙΑ στήλη του `fork` (και η δεξιά του `split`) είναι ΧΡΥΣΗ** = η πλευρά που «κερδίζει»: εκεί ο Σωκράτης,
   η αλήθεια, το «είναι» (Ηθικά 6: «Η ευδαιμονία δεν είναι | είναι», als-v756). Ουδέτερη σύγκριση → όποια σειρά λέει το βιβλίο.
9. **`ladder` = 3 σκαλιά**, χωρίς μακριά μονόλεξα/πολυτονικά στο μεγάλο κείμενο: στα 390 η στήλη είναι ~100px (με 2 σκαλιά
   η 3η στήλη μένει άδεια και το κείμενο πέφτει στις λεζάντες· «ἐπιθυμητικόν» → στο `sub`). Πίνακας περιεχομένων = `flow`, ποτέ σκάλα.
10. **ΚΟΙΤΑ κάθε σχέδιο** σε φωτογραφία 1440 + 390 (μόνο το `figure.dg` του σταθμού, `?s=n#sn`). Κουτάκι που σπάει
   λέξη-λέξη, κομμένο κείμενο, πλευρά χωρίς επικεφαλίδα → ξαναγράψε.

Δες έναν ζωντανό: `node -e "console.log(JSON.stringify(require('./tools/eisagogi/arxaia/politeia-b.json').stations[N-1].diagram,null,1))"`.

| Τύπος | Ταιριάζει όταν το βιβλίο λέει… | Δ2 |
|---|---|---|
| `flow` | μια **αλυσίδα** γεγονότων/προσώπων: Α → Β → Γ | I · ο χρησμός |
| `repeat` | μια **δοκιμή που επαναλαμβάνεται** με ίδιο αποτέλεσμα (κύκλος) | II · ο έλεγχος του χρησμού |
| `split` | **δύο αντίθετες αντιδράσεις** στο ίδιο πράγμα, με κοινή κατάληξη | III · θεϊκό / μίσος → καταδίκη |
| `fork` | **σύγκριση δύο πλευρών** σε σειρά κριτηρίων (κοινή ρίζα) | IV · σοφιστές / Σωκράτης |
| `dialogue` | μια **μέθοδος σε βήματα** με ρόλους (ποιος κάνει τι), σε φάσεις | V · διαλεκτική + μαιευτική |
| `descent` | μια **μετατόπιση** από ένα επίπεδο σε άλλο (πάνω → κάτω), με αρχαίο παράθεμα | VI · από τα άστρα στη γη |
| `ladder` | μια **άνοδος σε σκαλιά** από το χαμηλό στο ψηλό (παράδειγμα → γενίκευση) | VII · επαγωγική μέθοδος |
| `scales` | **ζεύγη ΑΛΗΘΙΝΩΝ αντιθέτων** ίδιας κατηγορίας (απαρίθμηση) + ένα νήμα — ⛔ χωρίς επικεφαλίδες | VIII · τα 6 ζεύγη |

Για βίο/χρονολόγιο (Πλάτων, Αριστοτέλης): `flow` (σταθμοί ζωής, ≤3) · `ladder` (άνοδος/εξέλιξη) · `split` (δύο εκδοχές) ·
`fork` (σύγκριση δύο έργων/φιλοσόφων). Για περιεχόμενο έργου (Ηθικά, Πολιτικά): `scales` (αντίθετα) · `ladder` (ιεραρχία) ·
`dialogue` (επιχείρημα σε βήματα) · `descent` (από το γενικό στο ειδικό).

## Τα σχήματα (μικρά παραδείγματα, από το Δ2)
```json
{ "type": "flow", "nodes": [ { "t": "Ο Χαιρεφών", "a": ["Ο Χαιρεφών"], "sub": { "t": "φίλος του Σωκράτη", "a": ["φίλος του Σωκράτη"] } }, … ] }

{ "type": "repeat",
  "top":    { "t": "«σοφός δεν είμαι» — «ο θεός δεν είναι δυνατόν να ψεύδεται»", "a": [...] },
  "stops":  [ { "t": "ένας από τους πολιτικούς", "a": [...], "find": { "t": "φαινόταν σοφός, αλλά σοφός δεν ήταν", "a": [...] } }, … ],
  "result": { "t": "αυτός νομίζει πως ξέρει · εγώ δεν νομίζω πως ξέρω", "a": [...] },
  "cost":   { "t": "και το μίσος «και αυτού και άλλων πολλών»", "a": [...] } }
   ⭐ ΥΠΟΧΡΕΩΤΙΚΑ εκτός Δ2 (als-v678): "topCap" + "resCap" (η προεπιλογή «Το ερώτημα / Το εύρημα» είναι του χρησμού του Δ2· Ε1: «Ο στόχος / Η κατάληξη»).

{ "type": "split", "lh": { "t": "κάτι το θεϊκό", "a": [...] }, "rh": { "t": "το μίσος", "a": [...] },
  "left": [ { "t": "ο Αλκιβιάδης", "a": [...] }, … ], "right": [ { "t": "οι θιγόμενοι και οι οπαδοί τους", "a": [...] }, … ],
  "result": { "t": "η θανατική καταδίκη του", "a": [...] } }

{ "type": "fork", "root": { "t": "αρνούνται να δεχτούν ως δεδομένο …", "a": [...] },
  "lh": { "t": "Οι σοφιστές", "a": [...] }, "rh": { "t": "Ο Σωκράτης", "a": [...] },
  "rows": [ { "l": { "t": "καταλήγουν στην **άρνηση**", "a": [...] }, "r": { "t": "**θετική αμφισβήτηση**", "a": [...] } }, … ] }

{ "type": "dialogue",
  "phases": [ { "t": "αναίρεση", "a": [...], "from": 0, "to": 2 }, { "t": "νέο συμπέρασμα", "a": [...], "from": 3, "to": 4 } ],
  "steps":  [ { "w": "ο συνομιλητής", "t": "εκθέτει μια άποψη που θεωρεί ολοκληρωμένη και θεμελιωμένη", "a": [...] }, … ],
  "result": { "t": "η γενική αλήθεια, ανεξάρτητη …", "a": [...] } }
   ↳ phases.from/to = δείκτες στα steps (0-based), συνεχόμενοι, χωρίς κενά.
   ⭐ ΥΠΟΧΡΕΩΤΙΚΑ εκτός Δ2 (als-v677): "lanes": ["αριστερά","δεξιά"] + "side":"R" στα βήματα της δεξιάς λωρίδας· προαιρετικό "resCap".
   Το «w» ΔΕΝ ζωγραφίζεται → το όνομα μπαίνει ΜΕΣΑ στο t («ο Λύκων: ρήτορας»).

{ "type": "descent", "top": { "t": "τα φυσικά φαινόμενα", "a": [...] }, "topNote": { "t": "έγιναν αντικείμενο της επιστήμης …", "a": [...] },
  "topGr": { "t": "*τὸ ζητεῖν τὰ περὶ φύσεως ἔληξε*", "a": [...] },
  "bottom": { "t": "ο ίδιος ο άνθρωπος και η κοινωνία", "a": [...] }, "bottomGr": { "t": "*περὶ δὲ τὴν χρήσιμον ἀρετὴν …*", "a": [...] } }
   ⭐ ΥΠΟΧΡΕΩΤΙΚΑ εκτός Δ2: "topCap" + "bottomCap" (οι λεζάντες· η προεπιλογή «Πριν / Με τον Σωκράτη» είναι του Δ2).

{ "type": "ladder", "lo": { "t": "η εμπειρία", "a": [...] }, "hi": { "t": "πέρα από την εμπειρία", "a": [...] },
  "rise": { "t": "*ἐπακτικοὶ λόγοι*", "a": [...] },
  "steps": [ { "t": "παραδείγματα", "a": [...], "sub": { "t": "από την καθημερινή ζωή και εμπειρία", "a": [...] } }, … ] }

{ "type": "scales", "pairs": [ { "l": "το καλό", "r": "το κακό", "a": ["του καλού και του κακού"] }, … ],
  "thread": { "t": "η λογική σκέψη, όχι οι αισθήσεις", "a": [...] } }
   ↳ pairs: l/r είναι σκέτα κείμενα, ΜΙΑ άγκυρα για το ζεύγος.
```
