# Μία ενότητα = ένα κείμενο (αυτό) + ένα όργανο (το άλλο skill), ένα push

**Χρυσός κανόνας: γράφεις ΜΟΝΟ `tools/gnosto/gkN.text.json`.** Το block της ενότητας στο
`arxaia-gnosto-data.js` **παράγεται** (`wire`), η πηγή **κόβεται** από το PDF (`source`), και ο
φρουρός στο `tests/arxaia-gnosto.test.js` είναι **γενικός** — νέα ενότητα = μηδέν γραμμές test.
Πρότυπο για κάθε πεδίο: `tools/gnosto/gk10.text.json` (εισαγμένο από τη ζωντανή gk10, deep-equal).

## 2 · Η ροή (εντολή → push)
1. `node tools/gnosto/keimeno.js scaffold gkN` — βρίσκει σελίδες, **προτείνει** rect αρχαίου (ζώνη ανάμεσα στην
   παραπομπή και την 1η γραμμή δύο στηλών) και αριστερής στήλης ανά σελίδα (w = μέσο ανάμεσα στις στήλες, κάτω
   όριο = η υπογραφή, επαληθευμένο με πραγματικό κόψιμο), title/short/cite/translator. Γράφει σκελετό + φύλλο
   `$TMPDIR/gnosto-gkN/geometry.txt` (`[ΑΡΧ] [ΜΑΘ] [ΥΠΟ] [ΣΕΛ]`). Διάβασε ΜΟΝΟ τις ⚠️ και, αν υπάρχουν, τις σελίδες τους.
   ⭐ Η μετάφραση που μαθαίνει = **η αριστερή στήλη** (ελεγμένο gk2–gk10). Βάλε το πλήρες όνομα (π.χ. «Γιώργος»).
2. `node tools/gnosto/keimeno.js source gkN` — κόβει, διασταυρώνει κάθε rect (page.string ή γραμμές της

3. Γράφεις `simple`, `gist`, `segs`, `pairs`, `counts` (§3, §4). Κείμενο = **αντιγραφή από την πηγή**, ποτέ πληκτρολόγηση.
4. `node tools/gnosto/keimeno.js check gkN` ως **0 ✗**. Κάθε ✗ λέει πού (`S7.m`, `pairs.c3`, `fixes[2]`) και
   δείχνει το σημείο απόκλισης `⟦…`. **Διορθώνεις το JSON, ποτέ τον κανόνα.**
5. `node tools/gnosto/keimeno.js wire gkN` — block `⟪gkN⟫ … ⟪/gkN⟫` στο τέλος του UNITS (ιδεμπότητο,

6. `node tests/arxaia-gnosto.test.js | tail -1` — ο γενικός φρουρός (§2δ) πιάνει τη νέα ενότητα μόνος του.
7. **Συνέχισε με το skill `arxaia-gnosto-organo`** (§3 βήματα 1–10) για την ΙΔΙΑ ενότητα. Ίδιο commit.
8. Όλα: `for f in tests/arxaia-*.js; do node "$f" | tail -1; done; node tests/launcher.test.js | tail -1; node tests/sync-regression.js | tail -1; ./smoke-test.sh`

## 3 · Η μορφή του JSON
```json
{ "id": "gk11", "added": "2026-10-20", "title": "…", "short": "Πολιτικά", "gist": "μία πρόταση",
  "author": "Αριστοτέλης", "cite": "Θ 1.3-2.1, 1337a33-b11", "translator": "Β. Μοσκόβης",
  "simple": ["≥3 γραμμές, ΜΟΝΟΤΟΝΙΚΑ"],
  "source": "tests/arxaia-enotita11.source.txt", "sourceSha": "(το γράφει το source)",
  "src": { "unit": 11, "anc": [{"page":104,"rect":[…]}], "mod": [{"page":104,"rect":[…]}, …] },
  "fixes":  [["ταιρ ιαστές", "ταιριαστές", "κενό μέσα σε λέξη (PDF, σελ. 105)"]],
  "counts": [["πόλ", 5, "«πόλ-» πέντε φορές (το λέει το ζευγάρι p5)"]],
  "segs": [
    { "a": "⟨Τί δέ|a1⟩; ", "m": "⟨Τότε|a1⟩; ", "end": true },
    { "a": "⟨ἦν|b4⟩ ¦δ’ ¦⟨ἐγώ|b5⟩", "m": "⟨είπα|b4⟩ ⟨εγώ|b5⟩" }
  ],
  "pairs": { "a1": ["Τί δέ", "Τότε", "⭐ ΜΕΤΑΒΑΤΙΚΗ ερώτηση: …"] } }
```
- `⟨κείμενο|κλειδί⟩` = κομμάτι με κλειδί · ό,τι είναι έξω = κομμάτι `0` · **`¦`** χωρίζει δύο διαδοχικά κομμάτια 0
  (μετράνε για τη Δομή του οργάνου: `structure.runs` δείχνει σε δείκτες κομματιών).
- `end: true` = τέλος παραγράφου/ατάκας **και στις δύο πλευρές μαζί**. Τα `ancient[]`/`text[]` παράγονται από εδώ.
- Μία περίοδος σπάει **μόνο** εκεί όπου σπάει και ο μεταφραστής. Οι περίοδοι μιας παραγράφου ενώνονται χωρίς
  κενό → το κενό ανάμεσά τους ζει στο τέλος του προηγούμενου κομματιού (`"; "`, `", "`).
- `fixes`: εφαρμόζονται στον **αχυρώνα** (μετά το κόλλημα των κενών), ποτέ στην πηγή. Το test απαιτεί το «από» να
  ΥΠΑΡΧΕΙ στο ωμό και να ΛΕΙΠΕΙ μετά. `counts` = regex (u-flag) στο αρχαίο· 4ο στοιχείο `"m"` = στη μετάφραση.

## 4 · Καλά ζευγάρια (πρότυπο: gk10)
- **Κλειδί = μία συντακτική μονάδα**, όχι λέξη-λέξη: «ἐκ τῶν προειρημένων» ↔ «από όσα έχουμε πει» είναι ΕΝΑ.
  Το ίδιο κλειδί δύο φορές σε μία πλευρά = ο μεταφραστής το ΕΠΑΝΑΛΑΜΒΑΝΕΙ ή το ΣΠΑΕΙ («Δεν … δεν»).
- Ό,τι ο μεταφραστής δεν αποδίδει (το «δ’» του «ἦν δ’ ἐγώ», «γάρ») ή προσθέτει («επίσης», «είναι») = κομμάτι **0**.
  ⛔ Ποτέ ζευγάρι-φάντασμα για να «υπάρχει».
- Εξήγηση `w`: **ΚΕΦΑΛΑΙΑ για τη λέξη-κλειδί** («ΑΠΡΟΣΩΠΗ έκφραση»), ⭐ για ό,τι εξετάζεται, μορφή → σύνταξη →
  γιατί ο μεταφραστής το απέδωσε έτσι. Οι **δραστηριότητες του βιβλίου** (Α.1, Β.2, Γ.4 της σελίδας δραστηριοτήτων)
  απαντιούνται ΜΕΣΑ στο ζευγάρι όπου πέφτουν («⭐ Η ΔΡΑΣΤΗΡΙΟΤΗΤΑ Γ.1: …»).
- ⛔⛔ **Κάθε αριθμός σε εξήγηση («ΤΕΣΣΕΡΙΣ φορές») μπαίνει στο `counts`** — μετρημένος στην πηγή, όχι στο μάτι.
- Παραθέματα αρχαίου μέσα στο `w` = αντιγραφή αυτολεξεί (οξεία ≠ βαρεία· εννοούμενο σε [αγκύλες] έξω από «»).

## 5 · Παγίδες (όλες πληρωμένες)
- ⚠️⚠️ **«. πεζό» = σχεδόν πάντα ΑΝΩ ΤΕΛΕΙΑ.** Το PDF γράφει «.» όπου το βιβλίο τυπώνει «·» (gk10 σελ. 97/98/101).
  Το PNG αποφασίζει: «·» → `fixes` `["είπε. το","είπε· το","ΑΝΩ ΤΕΛΕΙΑ (render σελ. N)"]`· τελεία → μένει.
- **Κενό μέσα σε λέξη** («επί σης», «μπο ρούν») και **ορατή παύλα** («παραδέ- χονται», και σε αλλαγή σελίδας) → fix.
- **Λέξη δύο φορές στην αλλαγή σελίδας** («δίνουν | δίνουν») → fix `["δίνουν δίνουν","δίνουν",…]`.
- **«¯» = παύλα** → ΕΝΑ fix `["¯","—","το PDF γράφει «¯» για παύλα"]` (split/join, πιάνει όλα).
- Το `page.string` σε μερικές σελίδες διαβάζει τις στήλες **εναλλάξ ανά γραμμή** (gk2 σελ. 23)· γι' αυτό το
  `source` διασταυρώνει και με τις γραμμές της γεωμετρίας. Αν αρνηθεί: το rect τρώει γράμμα → φάρδυνε το `w`.
- Γραμμές μετάφρασης με soft hyphen/«¯» έχουν **ύψος 15,5pt, όσο το αρχαίο** — ⛔ μη διαλέγεις στήλη με ύψος.
- Η υπογραφή μπορεί να **επικαλύπτει** την τελευταία γραμμή (gk7 σελ. 68): έλεγξε στο check ότι η μετάφραση
  κλείνει με τελικό σημείο (ο κανόνας το απαιτεί).
- ⛔ `--force` στο `source` αλλάζει την πηγή· μετά **ξανά `check`** (τα fixes μπορεί να μην χτυπάνε πια).
- Backticks μέσα σε `node -e "…"` τα εκτελεί το shell. Docs/μεγάλα JSON → `Edit`/`Write`, όχι heredoc με backticks.
